# Plataforma de Retos

## Tipos de Retos

Existen 2-3 categorías principales de retos:

1. **Aplicaciones reales útiles para portafolio**
2. **Aprendizaje de algoritmos**
3. **Retos para entrevistas** (a menudo diseñados como filtros capciosos)

### Ejemplos de retos basados en aplicaciones reales:
- Administración de una empresa con empleados y roles pagos
- Administración universitaria
- E-commerce con operaciones CRUD

## Rutas Adicionales para Encontrar Retos

Puedes encontrar más retos en los siguientes directorios:
- `Proyectos/Python/EJERCICIOS`
- `Proyectos/Java`

## Primer Filtro en el Proceso de Selección

El primer filtro suele ser realizado por reclutadoras, evaluando proyectos desplegados en plataformas como Railway.

## Plataforma de Curso Genérico Multi-lenguaje

La intención es crear una serie de ejercicios generales que sirvan para múltiples lenguajes de programación, diseñados como pequeños retos.

### Características requeridas:
- Cada lenguaje debe tener su propio REPL (Read-Eval-Print Loop)
- Cada prueba o reto debe incluir un test unitario que valide o rechace el resultado
- Estas pruebas deberían poder integrarse con el sistema de PERKS
- Los materiales del curso se encuentran en: `Proyectos/HTML/Curso_maestro`

## Plataforma de Hojas de Vida para Programadores

El objetivo es certificar el conocimiento mediante la obtención de PERKS, lo que debería facilitar:
- Las ofertas de trabajo para los candidatos
- El proceso de reclutamiento para las empresas
- Las entrevistas técnicas
