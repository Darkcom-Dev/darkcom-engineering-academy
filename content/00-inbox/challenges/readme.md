- Hay mas retos en `cd Proyectos/Python/EJERCICIOS`
- Hay mas retos en `cd Proyectos/Java`

# Plataforma de curso genérico multi lenguaje
La intensión es crear una serie de ejercicios generales que sirven para múltiples lenguajes de programación a manera de pequeños retos.
- La pagina debe contar con un REPL por cada lenguaje.
- Cada prueba o reto debe contar con un test unitario que valide o rechace el resultado del ejercicio.
- La intensión es poder unir estas pruebas a los PERKS
- Los cursos están en `cd Proyectos/HTML/Curso_maestro`

# Plataforma de hojas de vida para programadores.
La intensión es certificar el conocimiento, obteniendo los PERKS, esto debería facilitar las ofertas de trabajo para los reclutadores y los entrevistados.
