# Reto Calculadora

## Objetivos
- Aprende a usar un entorno virtual
- Aprende a usar GIT
- Sube el repositorio a Github[https://github.com]
- Aprende a que tus script se ejecuten desde la terminal, sin importar la ubicacion

## Que debe contener

- [ ] Debe contener una interfaz
- [ ] Botones con todos los numero del 0-9
- [ ] Debe contener Botones con las operaciones +-*/=, clear y C
- [ ] Debe contener menú con conversor de distintas unidades de medida
- [ ] Menú con Conversor de temperatura
- [ ] Menú con Conversor de presion
- [ ] Menú con Conversor de Código de Colores
- [ ] Menú con Conversor de Colores de resistencias
- [ ] Menú con Conversor de RGB a YUV
- [ ] Interfaz de calculadora Binaria
- [ ] Interfaz de calculadora Hexagesimal


## Como hacer el reto:

Crea un nuevo proyecto ya sea haciendo uso del script `create_python_project.py` o haciendo uso de los comandos manuales para hacerlo.

- [ ] Crea una carpeta con el nombre Calculator
- [ ] Asegúrate de instalar *venv* `pip3 install venv`
- [ ] Asegúrate de crear un repositorio GIT
- [ ] Crea un archivo calculator.py
- [ ] Aprende a usar tkinter (facil) * Opcional
- [ ] Aprende a usar urwid (dificil) * Opcional
