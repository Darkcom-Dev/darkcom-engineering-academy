# Plataforma de challenges.

La idea es proponer Retos de programacion reales que sirven en la industria, obtener ejercicios que normalmente los reclutadores buscan en un candidato.

Para empezar se podria comenzar usando los retos de Alkemy
- Backend - con Node
- Data Analitics - Python
- Frontend - Angular
- Fullstack - JS

Presentar estos retos en formato MD
Quizas una DB para categorizar los retos.
