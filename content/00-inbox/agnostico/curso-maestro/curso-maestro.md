# Programming Master Course

Este es un curso que fué diseñado por una universidad hace muchos años para alumnos que no son programadores y su rol final no es ese.

Este curso tiene la facilidad de ser muy básico hasta un nivel intermedio, quien sigue este curso al pie de la letra termina familiarizandose muy bien con el lenguaje de programación que esté estudiando.

Este curso lo adapté para que funcionara con cualquier lenguaje de programación, pues los temas son agnosticos a cualquier lenguaje de programación.

Este curso no pretende entregar ningun material de estudio, links, diplomas, videos, la idea es que si tienes dudas lo investigues por tu cuenta en internet.

- Esta es una web estática, por lo que el seguimiento de las clases debe hacerlo por su cuenta, ya que no cuenta con cuentas personales o bases de datos.
- Tampoco espere que esta web tenga una gran presentación, ya que está pensada para renderizarse en computadoras de 32 bits y navegadores de terminal.
- Si está siguiendo este curso en GitHub puede verlo en la [https://darkcom-dev.github.io/programming-master-course/](siguiente página)
- Si ha descargado el repositorio en local en un dispositivo Linux, puedes crear un softlink del index.html y llevartelo a tu carpeta de proyecto para facilitar el aprendizaje.
- Instala Ollama y algun modelo de lenguaje si vas a aprender en un entorno que no tenga internet y no tienes a quien preguntarle tus dudas.
