# Calcular producto

Bueno, seguimos calentando, aún no vamos a hacer un programa para lanzar un cohete al espacio, así que continuemos con otro ejercicio simple: Dados dos números reales mostrar su producto.

#### Entrada:
La entrada contiene dos líneas, cada una con uno de los números a multiplicar.
#### Salida:
El producto de los dos números.

| Ej. de entrada | Ej. de salida |
| -------------- | ------------- |
| 3.2 \| 4.0     | 12.8          |


```python
def calcular_producto(multiplicando, multiplicador):
    # Escriba su código aqui
    return multiplicando * multiplicador
```
