# Números multi-dígitos

Si lo revisas, el número 381654729 tiene todos los dígitos del 1 al 9, lo mismo ocurre con el 321654987. Obviamente, para que un número cumpla esta propiedad debe tener por lo menos 9 dígitos.

¿Qué tal si lo hacemos un poco menos estricto y determinamos si un número entero positivo tiene todos los dígitos del 1 al 5 por lo menos una vez (lo llamaremos multi-dígito)?

### Entrada

La entrada contiene una serie de líneas (no más de 1000), cada una con un valor entero positivo, y termina con un valor de 0 que no debe procesarse.

### Salida

Por cada valor de entrada la salida debe contener una línea con el mensaje (sin comillas ni tildes), 'Multidigito', o 'No es multidigito', según sea el caso.

| Ejemplo de entrada | Ejemplo de salida |
| ------------------ | ----------------- |
| 12345              | Multidigito       |
| 2518341            | Multidigito       |
| 54351              | No es multidigito |
| 999999999          | No es multidigito |
| 0                  |                   |
