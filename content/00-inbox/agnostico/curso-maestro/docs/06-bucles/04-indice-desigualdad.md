# Índice de desigualdad

Como pasa muchas veces en este país (aplica para muchos países), el gobierno, en un esfuerzo por ocultar la realidad, se inventó algo llamado “índice de desigualdad” con el que quiere mostrar que la desigualdad es poca y que la gente no tiene por qué estarse quejando tanto.

Consiste en lo siguiente: se toma el tercer mayor salario de todos los ciudadanos y se le resta el tercer menor, luego ese valor se divide por el cuadrado de la cantidad de ciudadanos de los que se tenía dato. Obviamente, el gobierno excluye de los registros aquellos ciudadanos desempleados por lo que todos esos valores son enteros positivos.

Aunque no estés de acuerdo con el gobierno, supongamos que te contrataron para programar ese cálculo y cómo eres un asalariado más y de algo tienes que vivir, muy a tu pesar lo harás. Aunque quizá en medio de ello guardes sin que se den cuenta los datos. para luego publicarlos en WikiLeaks u otro sitio y mostrar la realidad ;)

### Entrada

La entrada contiene una serie de líneas (más de 6 y no más de 10000000), cada una con el valor del salario de cada ciudadano y termina con un valor de 0 que no corresponde a ninguno.

### Salida

Una única línea con el valor del índice.

| Ejemplo de entrada | Ejemplo de salida |
| ------------------ | ----------------- |
| 200000             | 5000.0            |
| 500000             |                   |
| 999999             |                   |
| 700000             |                   |
| 900000             |                   |
| 300000             |                   |
| 400000             |                   |
| 600000             |                   |
| 100000             |                   |
| 800000             |                   |
| 0                  |                   |
