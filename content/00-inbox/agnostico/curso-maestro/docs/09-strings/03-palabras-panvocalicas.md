# Palabras panvocálicas

Considerando que el prefijo pan de origen griego significa “todo(a)” o “todo(as)” es fácil deducir que una palabra panvocálica es aquella que contiene todas las vocales. Esto sin importar el orden en que aparezcan, si tienen o no acento, si aparecen más de una vez, o si fonéticamente alguna vocal no “contribuye”. Algunos ejemplos de palabras panvocálicas son hipotenusa, murciélago, y arquitecto.
