# Reemplazar código de tipo con clase

## Problema
Una clase tiene un campo que contiene código de tipo. Los valores de este tipo no se utilizan en condiciones de operador y no afectan el comportamiento del programa.

## Solución
Cree una nueva clase y use sus objetos en lugar de los valores de código de tipo.
