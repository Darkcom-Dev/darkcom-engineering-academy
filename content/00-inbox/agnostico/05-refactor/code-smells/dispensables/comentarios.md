# Comentarios

- Si el método hace algo, dale un nombre autoexplicativo al método. Usa Renombrar Método para esto.
- Si necesitas afirmar reglas sobre un estado que es necesario para que funcione el sistema, usa Introducir Aserto.

## Beneficios

El código se vuelve más intuitivo y obvio.

## Cuándo ignorar

Los comentarios a veces pueden ser útiles:
- Cuando se explica por qué algo se implementa de una manera particular.
- Al explicar algoritmos complejos (cuando se han intentado todos los demás métodos para simplificar el algoritmo y no han tenido éxito).
