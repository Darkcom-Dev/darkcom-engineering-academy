# Lección 04: Texto Ordenado (Listas)

Las listas son fundamentales para organizar información secuencial o agrupada.

## Tipos de Listas

### 1. Listas Ordenadas (`<ol>`)
Se utilizan cuando el orden de los elementos es importante (ej. una receta o pasos a seguir).
- Se definen con `<ol>` (Ordered List).
- Cada elemento se define con `<li>` (List Item).

**Ejemplo:**
1. Prepara tu equipaje.
2. Compra tus boletos.
3. Dirígete al aeropuerto.

### 2. Listas No Ordenadas (`<ul>`)
Se utilizan para elementos agrupados donde el orden no es crítico.
- Se definen con `<ul>` (Unordered List).
- Cada elemento se define con `<li>`.

## Código de Ejemplo
```html
<!-- Lista Ordenada -->
<ol>
    <li>Paso uno</li>
    <li>Paso dos</li>
</ol>

<!-- Lista No Ordenada -->
<ul>
    <li>Elemento A</li>
    <li>Elemento B</li>
</ul>
```
