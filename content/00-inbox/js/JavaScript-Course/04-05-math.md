# Lección 05: El Objeto Math

`Math` es un objeto integrado en JavaScript que contiene propiedades y métodos para realizar operaciones matemáticas complejas.

## Métodos Comunes

| Método | Descripción | Ejemplo |
| --- | --- | --- |
| `Math.pow(b, e)` | Potencia (base elevada al exponente). | `Math.pow(2, 3)` -> 8 |
| `Math.sqrt(n)` | Raíz cuadrada. | `Math.sqrt(25)` -> 5 |
| `Math.PI` | El valor constante de PI. | `3.14159...` |
| `Math.round(n)` | Redondea al entero más cercano. | `Math.round(4.7)` -> 5 |
| `Math.floor(n)` | Redondea hacia abajo. | `Math.floor(4.9)` -> 4 |
| `Math.ceil(n)` | Redondea hacia arriba. | `Math.ceil(4.1)` -> 5 |

### Ejemplo en Código
```javascript
function calcularAreaCirculo(radio) {
    // Área = PI * radio al cuadrado
    return Math.PI * Math.pow(radio, 2);
}

console.log(calcularAreaCirculo(10)); // ~314.15
```
