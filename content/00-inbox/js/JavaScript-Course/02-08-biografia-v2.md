# Lección 08: Proyecto - Mi Biografía (V2)

¡Mejoremos nuestra biografía con lo aprendido en este módulo!

## Nuevas Herramientas
En esta versión, utilizaremos:
- **CSS Externo:** Crea un archivo `.css` para manejar todo el diseño.
- **DIVs y SPANs:** Para agrupar secciones y destacar palabras clave.
- **Selectores Avanzados:** Para dar estilos específicos a los enlaces o párrafos destacados.
- **Clases:** Para definir estilos reutilizables.

## Ejemplo de Estructura Mejorada
```html
<div class="contenedor-principal">
    <header>
        <h1>Mi Historia</h1>
    </header>
    
    <main>
        <section class="datos">
            <p>Nombre: <span class="resaltado">Tu Nombre</span></p>
        </section>
        
        <section class="historia">
            <h2>Sobre mí</h2>
            <p>Texto de tu biografía...</p>
        </section>
    </main>
</div>
```
