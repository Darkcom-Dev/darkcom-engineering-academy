# Lección 01: Estilo de Texto

En esta lección profundizamos en cómo dar formato al texto para resaltar información importante.

## Etiquetas de Estilo Comunes
A diferencia de las etiquetas semánticas, estas se enfocan más en la presentación visual (aunque en la web moderna, la mayor parte del estilo se maneja con CSS).

| Etiqueta | Función |
| --- | --- |
| `<u>` | Underline (Subrayado) |
| `<del>` | Deleted (Tachado) |
| `<sup>` | Superscript (Superíndice) |
| `<sub>` | Subscript (Subíndice) |

### Ejemplo
```html
<p>El agua se escribe H<sub>2</sub>O</p>
<p>El área es L<sup>2</sup></p>
```
